This directory the following tables:

- XXYY files contain 2d tables of cot(theta/2) and the time integral using
  pair-specfic ZBL screening functions from earlier calculations.
  
- SCATTAB is the same for the universal ZBL potential.

- SCATTAB_big is the same as SCATTAB, but with finer resolution.

- tersoff_repulsive.tab is the same for the repulsive part of the Tersoff
  potential, details unknown. This file has been generated to allow 
  comparison with MD simulations, but are probably of no use anymore.
