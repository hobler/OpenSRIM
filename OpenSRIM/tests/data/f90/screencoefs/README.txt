
This directory contains data for coefficients of sum-of-exponentials 
functions describing the screening function.

The following files are included:

NLH_coeffs.dat : Coefficients for the fits of a sum-of-three-exponentials 
function to the DMol data sets (the Nordlund-Lehtola-Hobler potential). 
Because of problems with the B-Ne pair described in the publication, the 
coefficients for the B-Ne pair (Z1=5, Z2=10) have been obtained by fitting 
to the MP2 results. The first line defines the order of the values.

NLHlin_coeffs.dat : Same as NLH_coeffs.dat, but with an additional linear 
term that brings the screening function down to 0 at R=Rmax. 

ZBLspec_coeffs.dat: Coefficients for a sum-of-four-exponentials fit to the 
pair-specific ZBL potentials. It is a copy of the file "POTCOEF03.DAT" 
from SRIM-2013 (http://www.srim.org), used by permission of Jim Ziegler. 
It has 10 columns:

   Z1  Z2  a1  b1  a2  b2  a3  b3  a4  b4

Z1 and Z2 are the atomic numbers of the atoms, ai and bi are the coefficients
of the screening function Phi of the interatomic potential:

   Phi(R) = sum_i( ai * exp(-bi*R) )

R is the reduced internuclear distance defined by

   R = r / aZBL

where r denotes the internuclear distance in Angstroms and

   aZBL = 0.468 / (Z1**0.23 + Z2**0.23)

is the ZBL screening length.

From some historical notes in the SRIM package it seems that this file has
been generated by Jochen Biersack by fitting the sum-of-exponentials to
pair-specific screening functions calculated according to the procedure
described in the ZBL book (J.F. Ziegler, J.P. Biersack, U. Littmark, The 
Stopping and Range of Ions in Solids, Pergamon Press, New York, 1985, 
Chapter 2). It is not and apparently has never been used in SRIM.

Comparison of screening functions calculated with the data contained in the 
file "ZBL_coeffs.dat" with numerically calculated pair-specific ZBL screening 
functions indicates that the former are indeed fits to the latter.
