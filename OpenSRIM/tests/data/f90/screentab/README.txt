
This directory contains screening functions obtained from DMol and ZBL 
calculations. 

The subdirectories contain the following data.

- DMol : original DMol calculations

- DMol_pos : DMol calculation with negative values cut off. 

- ZBLspec : redone ZBL calculations

- ZBLspec_pos : ZBL calculations with negative values cut off. 

- ZBLuniv : numerical data point list for the universal ZBL function 
  (sum of four exponentials) for selected atom pairs.
