
This directory contains the screening functions obtained from the ZBL 
pair-specific calculations. Values <0 are cut off.

The screening functions are named

screening_zbl_1_1.dat
screening_zbl_1_2.dat

and so on. In the file name, the first number after "zbl_" stands for the 
atomic number Z1 and the following number for Z2. Due to symmetry, the Z1 
and Z2 are interchangeable, i.e. the screening function for Z1=1 and Z2=2 
is the same as for Z1=2 and Z2=1 and so forth.

The meaning of the columns and units are:

column 1: distance between the two atoms in Angstroms
column 2: screening function, unitless
