This directory contains the screening functions for the repulsive parts of the interatomic potentials calculated with DMol, provided by Kai Nordlund. See K. Nordlund, S. Lehtola, G. Hobler, Repulsive interatomic potentials calculated at three levels of theory, Phys. Rev. A 111 (2025) 032818.

The directory was originally named `dmol_endsettozero_screen_new`.
