# Sample Files for MC Results Single Plot Mode

Use these files via `MC Results -> Single Plot -> Load Data...`.

- `single_xy.json`
  - Direct JSON curve with explicit `x` and `y`.
- `nested_series.json`
  - Nested JSON with shared x-axis (`energy`) and multiple y-series.
- `list_of_curves.json`
  - JSON list of multiple curves (`name`, `x`, `y`).
- `depth_profiles.csv`
  - Comma-separated table with header and multiple y-columns.
- `energy_scan_semicolon.csv`
  - Semicolon-separated table for delimiter auto-detection.
- `range_curve.txt`
  - Whitespace-separated text with comment line and two columns.
- `single_column_counts.txt`
  - Single numeric column text file (index-based x-axis).
