This directory the following tables:

- DEFECTS and DEFECTSMD contain coordinates of atoms around various defect 
  types in Si.

- gauss_legendre.dat is a list of abscissas and weights for Gauss-Legendre 
  quadrature.

- rhoe.dat and rhozbl.dat are electron distributions used for electronic 
  stopping power calculations. These calculations were unsuccessful and the 
  files are kept for historical reasons only.

Other tables are in subdirectories, see there for README files.
