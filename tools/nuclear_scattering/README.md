This directory contains the following code:

- `zbl.py`, `krc.py`, and `nlhlin.py`: Calculate screening functions and their derivatives.
- `apsis.py`, `apsis_alt.py`: Calculate the apsis of a collision.
- `cm_scatter.py`: Calculate the scattering angle in the CM system and the time integral.
- `scatter.py`: Testing of the calculation of the scattering angle and time integral. This includes an MD simulator of a binary collision.
- `sn.py`: Calculate the nuclear stopping cross section and straggling for e set of reduced energies.
- `sn_fit.py`: Fit the data produced by `sn.py` by analytic functions and make tables of the parameters.
- `rp.py`: Calculate projected ranges using the tables produced by `sn_fit.py`.
